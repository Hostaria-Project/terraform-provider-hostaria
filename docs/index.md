# Hostaria Provider

Provider Terraform et OpenTofu pour [Hostaria](https://hostaria.cloud).

La clé `api_key` est une clé `host_live_…` créée dans le [compte Hostaria](https://hostaria.cloud), section IaC. Elle peut aussi venir de `HOSTARIA_API_KEY`.

## Example Usage

```terraform
terraform {
  required_providers {
    hostaria = {
      source  = "hostaria-project/hostaria"
      version = "0.1.2"
    }
  }
}

provider "hostaria" {}

data "hostaria_offer" "starter" {
  name = "Starter"
}

data "hostaria_os" "ubuntu" {
  slug = "ubuntu-24-04"
}

resource "hostaria_vps" "web" {
  offer_id = data.hostaria_offer.starter.id
  os_id    = data.hostaria_os.ubuntu.id
  name     = "web-01"
}
```
